🔧 Side Panel Debug Guide

Instructions: 1. Open your main Map.in page in another tab 2. Open Developer Console (Press F12) 3. Run the commands below in the console

🧪 Quick Test

Copy and paste this into the browser console on your Map.in page:

testSidePanel()

🔍 Step-by-Step Debugging

1. Check if elements exist

// Should return true for all elements
console.table({
  placeholder: !!document.getElementById('spPlaceholder'),
  content: !!document.getElementById('spContent'),
  title: !!document.getElementById('spTitle'),
  desc: !!document.getElementById('spDesc'),
  stats: !!document.getElementById('spStats'),
  facts: !!document.getElementById('spFacts'),
  events: !!document.getElementById('spEvents')
});

2. Check if data is loaded

// Should show data is available
console.log('States available:', Object.keys(window.statesData || {}).length);
console.log('Sample state data:', window.statesData?.Maharashtra);
console.log('showPanel function:', typeof window.showPanel);

3. Check if handlers are attached

// Should show states with event handlers
const states = document.querySelectorAll('.state');
console.log('Total states found:', states.length);
console.log('States with handlers:', Array.from(states).filter(s => s._hasHandlers).length);

4. Test showPanel function manually

// Should display Maharashtra info in side panel
if (window.statesData?.Maharashtra && window.showPanel) {
  window.showPanel(window.statesData.Maharashtra, 'states');
  console.log('✅ Maharashtra panel should now be visible');
} else {
  console.log('❌ Missing data or showPanel function');
}

5. Test state hover simulation

// Simulate hovering over Maharashtra
const mh = document.getElementById('Maharashtra');
if (mh) {
  mh.dispatchEvent(new MouseEvent('mouseenter', { bubbles: true }));
  console.log('✅ Triggered mouseenter on Maharashtra');
} else {
  console.log('❌ Maharashtra element not found');
}

6. Test timeline click

// Click on 2025 timeline item
const timeline2025 = document.querySelector('[data-year="2025"]');
if (timeline2025) {
  timeline2025.click();
  console.log('✅ Clicked 2025 - panel should show timeline info');
} else {
  console.log('❌ 2025 timeline item not found');
}

7. Manual panel control

// Force show the panel (if everything else fails)
const placeholder = document.getElementById('spPlaceholder');
const content = document.getElementById('spContent');
const title = document.getElementById('spTitle');
const desc = document.getElementById('spDesc');

if (placeholder) placeholder.classList.add('hidden');
if (content) content.classList.remove('hidden');
if (title) title.textContent = 'Manual Test - Maharashtra';
if (desc) desc.textContent = 'This is a manual test to check if the side panel can be shown.';

console.log('✅ Panel should now be visible with test content');

🚨 Common Issues & Fixes

Issue: No states found (0 states)
Fix: The SVG map might not be loaded. Check if the SVG has class="state" paths.
Issue: showPanel function not found
Fix: script.js might not be loaded properly. Check for JavaScript errors in console.
Issue: Panel elements not found
Fix: Check if index.html has the correct side panel structure.
Success: If testSidePanel() shows all green checkmarks, the side panel should work when you hover over states or click timeline items.

📱 Expected Behavior

  • ✅ Hovering over any state on the map shows state information in the right panel
  • ✅ Clicking timeline years (1947, 1950, etc.) shows historical information
  • ✅ Clicking different tags (States, Rivers, Forts) changes the content type
  • ✅ Panel should be on the RIGHT side of the screen (not bottom)

🎯 Final Test

If everything is working, this should show Maharashtra info:

// Complete test sequence
console.clear();
console.log('🧪 Running complete side panel test...');

// Test data
if (window.statesData?.Maharashtra) {
  console.log('✅ Data: Maharashtra found');
} else {
  console.log('❌ Data: No Maharashtra data');
}

// Test function
if (typeof window.showPanel === 'function') {
  console.log('✅ Function: showPanel available');
  
  // Test call
  window.showPanel(window.statesData.Maharashtra, 'states');
  console.log('✅ Called: showPanel with Maharashtra');
  
  // Check if panel is visible
  const content = document.getElementById('spContent');
  const placeholder = document.getElementById('spPlaceholder');
  
  if (content && !content.classList.contains('hidden')) {
    console.log('✅ Panel: Content is visible');
  } else {
    console.log('❌ Panel: Content not visible');
  }
  
  if (placeholder && placeholder.classList.contains('hidden')) {
    console.log('✅ Panel: Placeholder is hidden');
  } else {
    console.log('❌ Panel: Placeholder still visible');
  }
  
} else {
  console.log('❌ Function: showPanel not available');
}

console.log('🧪 Test complete - check results above');
