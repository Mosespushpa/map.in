Side Panel Test

Open index.html and run these in the browser console:

Test Commands:

// 1. Check if statesData is loaded
console.log('statesData:', Object.keys(window.statesData || {}).length, 'states');

// 2. Check if showPanel exists
console.log('showPanel exists:', typeof window.showPanel === 'function');

// 3. Test showing a state
if (window.statesData && window.statesData.Maharashtra) {
    window.showPanel(window.statesData.Maharashtra, 'states');
    console.log('✅ Should show Maharashtra info');
}

// 4. Check panel elements
console.log('Panel elements:', {
    placeholder: document.getElementById('spPlaceholder'),
    content: document.getElementById('spContent'),
    title: document.getElementById('spTitle')
});

// 5. Manually show panel
const testData = {
    name: 'Test State',
    capital: 'Test City',
    description: 'This is a test',
    facts: ['Fact 1', 'Fact 2']
};
if (typeof window.showPanel === 'function') {
    window.showPanel(testData, 'states');
}

Quick Checks:

  • Open Developer Tools (F12)
  • Go to Console tab
  • Copy and paste the commands above
  • Look for green checkmarks and any errors

Expected Results:

  • statesData should show ~28 states
  • showPanel should exist (true)
  • Panel should update when showPanel is called
  • No red errors in console
